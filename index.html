📚 Materi Coding

Pilih materi yang ingin kamu pelajari.

1. Belajar HTML

HTML adalah bahasa markup untuk membuat struktur website.

<h1>Halo Dunia!</h1>
<p>Aku sedang belajar coding.</p>
<button>Klik Aku</button>

Penjelasan:

  • <h1> membuat judul.
  • <p> membuat paragraf.
  • <button> membuat tombol.

2. Belajar CSS

CSS digunakan untuk mengatur warna, ukuran, dan tata letak website.

h1 {
  color: blue;
  text-align: center;
}

color mengubah warna teks. text-align mengatur posisi teks.

3. Belajar JavaScript

JavaScript membuat website bisa merespons tindakan pengguna.

function sapa() {
  alert("Halo, coder!");
}

Fungsi alert() menampilkan pesan popup.
